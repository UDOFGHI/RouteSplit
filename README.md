# RouteSplit

Приложение для Windows 10/11 x64, которое разделяет интернет-подключения программ поверх уже подключённого **hidemy.name OpenVPN**.

Выбранные исполняемые файлы работают через VPN. Остальные новые обычные IPv4-подключения направляются через Ethernet или Wi-Fi напрямую.

## Скачать и установить

Установщик опубликован в разделе **Releases** этого репозитория. Распаковывать дополнительные файлы не нужно.

1. Если RouteSplit уже работает, нажмите «Выключить», дождитесь завершения и закройте окно.
2. Запустите `RouteSplit-Setup-0.1.2.exe` и подтвердите запрос Windows.
3. Установите приложение и подключите hidemy.name в его обычном клиенте.
4. Откройте RouteSplit, выберите VPN-адаптер и обычный Ethernet/Wi-Fi, добавьте нужные EXE.
5. Нажмите «Проверить два IP», затем «Включить». Перезапустите программы, чтобы они создали новые соединения.

Для просмотра окна права администратора не нужны. Сетевая часть запрашивает их при включении. Установка по умолчанию — в `C:\Program Files\RouteSplit`; создаются ярлыки и запись удаления в настройках Windows. Требуется .NET Framework 4.8.

## Возможности

- Правила по полному пути к EXE; выбор файлов или запущенных программ.
- Перехват TCP и UDP через ProxyBridge / WinDivert.
- Проверка внешних IP каждого адаптера.
- Временные прямые маршруты и их восстановление при завершении сеанса.
- Кнопка восстановления после прерванного запуска.

## Ограничения тестовой версии

- Целевая конфигурация — hidemy.name OpenVPN с IPv4. Совместимость со всеми VPN, играми и античитами не проверена.
- Правила относятся к новым соединениям. Вспомогательные EXE и новые пути после обновления программы нужно добавлять отдельно.
- Системный DNS использует настройки Windows; разделения DNS по приложениям нет.
- ICMP и сырые сокеты не перенаправляются. Защищённые процессы могут не определяться движком.
- Независимого системного kill switch нет; гарантия отсутствия утечек не предоставляется. Если владелец соединения не определён, оно может остаться на обычном маршруте.
- После выключения RouteSplit снова действуют исходные настройки клиента VPN.
- Установщик приложения не подписан сертификатом издателя. Подписанный драйвер WinDivert входит в комплект.

Локальные проверки TCP/UDP, загрузки библиотек, установки, повторной установки и удаления выполнены в изолированной тестовой папке. Полная проверка установки в Program Files и маршрутизации произвольных реальных приложений не завершена.

## Исходники и сторонние компоненты

Этот репозиторий предназначен для распространения установщика и документации. Собственные исходники RouteSplit хранятся в отдельном закрытом репозитории и не включены в этот установщик.

В комплекте сохранены лицензии [ProxyBridge 4.3.0](https://github.com/InterceptSuite/ProxyBridge/tree/v4.3.0_Windows) и [WinDivert 2.2.2](https://github.com/basil00/WinDivert/tree/v2.2.2), а также архив исходников WinDivert. Они относятся к сторонним библиотекам. Файл `THIRD-PARTY.txt` описывает их и способ использования совместимой замены динамических библиотек без пересборки RouteSplit.
