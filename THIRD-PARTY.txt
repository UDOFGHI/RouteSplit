Compatible dynamic library replacement:
Close RouteSplit and its network session. In the application directory, create
a UTF-8 text file named native-libraries.custom containing exactly:
allow-compatible-replacements

RouteSplit will then allow compatible replacement native libraries without
requiring recompilation of the application. The default SHA-256 checks apply
when this file is absent. Windows still applies its own kernel driver signature
requirements. The native libraries must retain their filenames and public ABI.
Reverse engineering for debugging modifications to the LGPL library is permitted.

No RouteSplit application source is included in this public package.
